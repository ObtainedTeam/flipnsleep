# Projectskills (Obtained)

Gedeelde skills voor Claude Code. Elke sessie die in deze repo werkt (cloud, VS Code of desktop) laadt ze automatisch.

| Skill | Bron | Waarvoor |
| --- | --- | --- |
| grill-me / grilling | mattpocock/skills (MIT) | Eerst doorvragen op een plan voordat er code komt. Start met /grill-me |
| brainstorming | obra/superpowers (MIT) | Intentie, ontwerp en eisen uitwerken voor een nieuwe feature |
| frontend-design | anthropics/skills | Eigen visuele richting in plaats van standaard AI-design |
| impeccable | pbakaus/impeccable (Apache 2.0) | Art direction, audit en polish van UI; downloadt bij eerste gebruik een eigen engine van GitHub |
| web-interface-guidelines | vercel-labs/web-interface-guidelines (MIT) | UI controleren op toegankelijkheid, focus, formulieren, layout |
| code-simplifier | anthropics/claude-plugins-official | Recente code opschonen zonder gedrag te veranderen |

Bijwerken: de bron opnieuw ophalen en de map vervangen. Niet zelf in de bestanden van derden schrijven.
